# 后续扩展预留

当前只实现四条件多任务主实验，不将消融任务放入主实验队列。此目录为后续独立模块的固定位置，暂不提供假装可运行的空训练入口。

建议未来模块：

- `formation_ratio/`：形成/操作比例曲线，允许0/1端点。
- `data_scale/`：冻结数据的嵌套前缀曲线。
- `equal_budget/`：单训/混训、条件间的预算对齐补充。
- `long_rollout/`：额外推演长度，独立评测协议，不覆盖当前32步成绩。
- `qualitative/`：形成过程与预测状态可视化。

## 接口约定

1. 数据来源仍由 `data.audit.verify()`验证；不得自动重新生成已冻结任务。
2. 主实验 `protocol.json`保持不可修改；扩展创建自己的协议、任务表和独立输出，建议 `runs/extensions/<模块>/<运行名>`。
3. 复用 `training.sampler`、公共模型/损失和 `evaluation.evaluate`的状态评分接口；改变预算/采样/终态定义必须写清新版本。
4. 新的形成比例端点不能偷偷进入四条件主实验，应由扩展模块自己的协议校验处理。
5. 扩展优先在T01锚点任务验证，是否推广到全部任务由后续研究决定。
6. 新模块目录补README、真实微型测试和help入口；不覆盖历史预实验及main结果。
