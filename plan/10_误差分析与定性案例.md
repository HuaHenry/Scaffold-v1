# 10 误差分析与定性案例

优先级 P2 ｜ 对应：解释性分析 ｜ 依赖：实验 03 的 run（无新训练）｜ 公共约定见 `00`

## 1. 目标

解释模型在哪里对、在哪里错：按场景、按材料、按错误类型拆分，并产出定性图（预测 vs 真值）和失败案例集。

## 2. 意义

- 整体平均数可能掩盖相反的趋势（process 在拱形上受益、在沙丘上受损）。
- 审稿人关心模型是否犯不符合物理的错误，需要错误类型分解和肉眼可读的图。
- 为论文定性图（Fig.6）和附录失败案例提供素材。

## 3. 实验设计

读取 `runs/main/*/eval_samples.npz`（含预测终态与逐样本指标），不重新推演。

1. **分场景**：按 `scene_kinds` 分组（`id` 的 10 种，OOD 的组合名），报告各条件的连锁 F1、`cell_acc_mask`、排序准确率及样本数。重点：arch（临时脚手架，依赖顺序最强）、cottage / hut（多层、背景物依赖前景）、dune / pond（流体，随机性大）、tree（叶的连通规则）。
2. **分材料**：对真值变化格，按变化前材料与变化后材料分类（石、木、砖、屋顶瓦、门、叶、沙、水、背景墙 / 窗 / 火把 / 梯子 / 花），报告每类召回率与混淆矩阵（真值新材料 × 预测新材料），重点：结构块被预测成松散材料、背景物未清除、门未随地基坠落。
3. **错误类型**（互斥，按优先级）：未响应（预测 == 初态但真值有连锁）、只执行动作（预测 == `apply_edit` 结果）、连锁不全（预测变化格是真值的真子集）、多余变化、材料错、物理违规、完全正确。按条件、划分统计占比。
4. **定性图**：12 个样本（每划分 3 个：该划分中 state 与 process 连锁 F1 差值最大的 1 个、最小的 1 个、随机 1 个，固定种子），5 列：初态 / 真值终态 / state / process / partial 预测，用 `render_layers(fg, bg, 6)`。
5. **失败案例集**：每个条件取连锁 F1 最低的 20 个样本，输出 `results/failures/{condition}/{idx}_{split}.png`（初态、真值、预测上下排列，差异格红框，被拆格红、连锁格黄），并生成 `failures.md` 索引（场景、干预、错误类型）。

## 4. 实现（本实验独有部分）

```bash
python -m exp.analysis.by_scene    --exp main --out results/by_scene.json --table results/tables/by_scene.md
python -m exp.analysis.by_material --exp main --out results/by_material.json

```

用 `PIL` 拼图并加标注，统一字体配色，导出 PNG 与 PDF。产出图表：Fig.6、Table 3 的分场景 / 分材料部分、附录失败案例。

## 5. 验收标准

1. 分场景样本数之和等于 bench 总数；错误类型互斥且合计 100%（pytest）。
2. 混淆矩阵的行和等于对应材料的真值变化格数。
3. 定性图选样规则固定、可复现；失败案例文件名含 split 与样本编号。

## 6. 预期结果（先验判断）

- arch / cottage 上条件间差别最大，dune / pond 上最小且噪声最大。
- 最常见的错误：连锁不全（预测了部分坍塌但漏掉上层）与只执行动作，其次背景物未清除；state 模型可能更常"只执行动作"。
- 按材料：松散材料召回率低于结构块；门的整体坠落是最易出错的特例之一。
- 这些是假设，分解结果可能推翻它们；价值在于诚实呈现。

## 7. 风险与备选

- 小样本分组（例如 `id` 中 pond 只有 9 个）数字不稳：表中标 n，n < 15 的格子浅色显示，不做结论。
- 时间紧时只做分场景、错误类型与定性图，完整混淆矩阵放附录。
