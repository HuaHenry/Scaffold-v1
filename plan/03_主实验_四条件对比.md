# 03 主实验：四条件对比（state / process / partial / shuffle）

优先级 P0 ｜ 对应假设：H1、H2 ｜ 前置：实验 01、02 的结论为"继续" ｜ 公共约定见 `00`（环境 §1、协议 §5、指标 §6、基线 §7、训练 §9、统计 §12）

## 1. 目标

在相同的模型、步数、超参、评测下，比较四种训练数据条件对 FormBench 的影响：

- **H1**：process 是否优于 state？
- **H2**：process 的优势（若存在）是否来自**连续的形成转移**？即 process 是否优于 partial（见过中间态但无连续形成）与 shuffle（同样的帧、顺序被打乱）。

## 2. 意义

这是论文的核心表。四个条件保证：场景相同、帧预算相同（每 episode 64 帧）、操作片段的干预相同（process 的 4 个操作片段与 state 的前 4 个片段逐帧相同），只有"帧之间的时间结构"不同。

| 条件 | 想隔离的因素 |
| --- | --- |
| state | 基线：只见成品及其运作 |
| process | 完整、有序的形成过程（代价：操作片段减半） |
| partial | 见过等量未完工结构，但每个片段独立重置，没有形成转移 |
| shuffle | 与 process 完全相同的帧，仅顺序被打乱 |

## 3. 实验设计

- 训练：4 条件 × 3 种子 = 12 个任务，协议 `video`，配置 `exp/configs/frozen.json`。
- 补充：4 条件 × 3 种子，协议 `causal`（P1，时间不够只跑 1 个种子），用于证明 shuffle 在 `causal` 下等价于只有操作片段。
- 评测：每个 run 在 bench 的 4 个划分 × 2 个干预上推演（00 §10），指标见 00 §6；参照 00 §7 的四个基线。
- 统计：00 §12；比较对 process-state、process-partial、process-shuffle、state-shuffle、partial-state。

## 4. 实现（本实验独有部分）

```bash
python -m exp.make_jobs main            # 生成 exp/jobs/main.json 与 main_causal.json
python -m exp.run_queue --jobs exp/jobs/main.json --gpus 0,1,2,3 --eval-after
python -m exp.aggregate --exp main --out results/main.json --table results/tables/main.md
```

`make_jobs main`：枚举 `condition ∈ {state,process,partial,shuffle}` × `seed ∈ {0,1,2}`，`out = runs/main/{condition}_s{seed}`，其余全部取自 00 §9。实验 01 已训练 `state_s0..s2`、实验 02 已训练 `{state,process,partial,shuffle}_s0`，同名 `out` 目录已有 `done.json`，队列自动跳过（00 §11），不重训。产出图表：Fig.3、Fig.4、Table 2。

## 5. 验收标准

1. 12 个 `video` 任务全部完成且各有 `eval.json`，缺任何一个不得出表。
2. 种子数与确认集按实验 01 的 `recommendation` 执行（`MDE(id) > 0.04` 则 5 个种子并加第二份 bench）；同一条件种子间 std 与实验 01 的 `σ_seed` 同量级，否则查原因。
3. 各条件训练 loss 在最后 1000 步变化 < 3%。
4. 所有模型在 `id` 的连锁 F1 均显著高于 `apply_edit`（否则是训练问题，回到 00 §13）。
5. 主表数字由 `aggregate.py` 一键重现。

## 6. 预期结果（先验判断，不是测量值）

四个条件的差距预计不大（连锁 F1 相差几个百分点量级），因为绝大多数转移恒等、每次干预的连锁只有约 3–9 格、形成片段中物理引起变化的转移只占 9.6%（00 §14）。

| 情景 | 现象 | 先验 | 论文叙事 |
| --- | --- | --- | --- |
| A 强成功 | process 在 OOD 连锁 F1 显著高于 state / partial / shuffle | ~20% | 形成缺口存在，形成过程可弥补 |
| B | process 优于 state，但 partial >= process | ~35% | 增益来自见到未完工结构（状态多样性），非因果转移；对 H2 是否定，仍有价值 |
| C 无差异 | 所有条件在 CI 内重叠 | ~35% | 该规模下形成缺口不显著；结合实验 07、08 进一步分析 |
| D | process 因少一半操作片段而更差 | ~10% | 报告预算权衡；结合实验 07 |

较有把握的预期：shuffle 在 `video` 协议下不优于 state，可能略差（7,936 个非物理跳变等于噪声监督）；`causal` 下 shuffle 等价于只有 4 个操作片段；partial 的操作转移中物理引起变化占比（38.2%）略高于 state（36.2%），可能带来小幅增益；所有条件 OOD 低于 `id`，`scale_ood` 最低。结果出来后按实际情景选叙事，不要为了某个叙事挑指标或划分。

## 7. 风险与备选

- 差异被噪声淹没：种子加到 5；用新种子再生成一份 bench 作第二测试集（先排除与训练成品重复的结构）。
- process 少一半操作片段不公平：由实验 07 补充。形成片段缺少失误负例：由实验 08 补充。
