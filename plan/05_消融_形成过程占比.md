# 05 消融：形成过程占比

优先级 P1 ｜ 对应假设：H1（剂量-反应）｜ 公共约定见 `00`（数据变体接口 §2）

## 1. 目标

总帧数固定为 64，改变形成片段的占比，观察性能是否随形成过程增加而单调变化。

## 2. 意义

H1 的任何因果解释都应有剂量-反应关系：形成过程越多，对结构的理解越好（或至少不更差）。若无剂量关系，实验 03 的差异更可能来自偶然或数据分布副作用。

## 3. 实验设计

形成帧数 `F ∈ {0, 8, 16, 32, 48}`，对应操作片段数 `n_clips = (64-F)/8 ∈ {8, 7, 6, 4, 2}`。

- F=0 即 `state`、F=32 即 `process`，直接复用实验 03 的 run；新训 F=8、16、48，共 3 个设定 × 3 种子 = 9 个任务。
- 同一场景、同一世界种子；操作片段取 `events[:n_clips]`，不同 F 的操作片段是前缀嵌套的。
- 主方案 `formation_mode=compress`：把整个建造过程均匀压缩进 F 帧（F 小则每帧动作多、时间步粗），末尾保留 4 帧沉降。副方案 `prefix`：保持每帧动作数，只展示前 F 帧（用于区分"数据少"与"时间步粗"，时间不够可不做）。
- 协议 `video`，步数与超参同 00 §9，3 个种子。

## 4. 实现（本实验独有部分）

使用 00 §2 的数据变体接口；`F >= 6`。

```bash
for F in 8 16 48; do
  python run.py --gen-train --data-dir output/data_f$F --F $F --n-clips $(( (64-F)/8 )) --conditions process
done
python -m exp.make_jobs formation_ratio
python -m exp.run_queue --jobs exp/jobs/formation_ratio.json --gpus 0,1,2,3 --eval-after
python -m exp.analysis.dose_response --out results/dose_response.json
```

`dose_response.py`：画 `F -> 连锁 F1`（每划分一条线，误差棒为种子 std），报告 Spearman 相关与线性趋势检验。产出图表：Fig.7 的一格。

## 5. 验收标准

1. 五个设定的帧预算均为 64，各 3 个种子全部完成。
2. F=0 / F=32 的结果直接复用实验 03，不重训。
3. 每个 F 的 `audit.json` 显示场景分布、动作类型分布与主数据一致。

## 6. 预期结果（先验判断）

- 若形成过程有用：连锁 F1 随 F 增加先升后降（F 过大时操作片段太少），最佳点可能在 F=16–32。
- 若无用：曲线随 F 增加单调下降，F=48 最差。
- OOD 划分的曲线幅度大于 `id`（若 H3 成立）。
- 先验：整体平缓（几个百分点内）约 50%，倒 U 型约 25%，单调下降约 25%。

## 7. 风险与备选

- F=8 时每帧压缩约 9 个动作，转移跨度很大，可能显得形成过程有害；这正是需要副方案 `prefix` 的原因。
- 预算紧张时只做 F ∈ {16, 48}，已能给出趋势。
