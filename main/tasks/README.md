# 任务定义与生成器

`registry.py`定义17个固定ID，`physics_tasks.py`生成新16任务。当前03整体为T01，不将其内部建筑类别再算独立任务。

| ID | 任务 | 严格边界 |
|---|---|---|
| T01 | 当前结构干预基准 | 完整03来源，结构破坏及原困难测试；不拆塔/桥/房屋 |
| W01 | 开放平地落水 | 无容器、障碍、坡或坑 |
| W02 | 容器侧壁释放 | 独立地上容器，仅拆侧壁，无外接通道 |
| W03 | 单坡导流 | 相邻列连续下降的单坡，无水平多级平台 |
| W04 | 阶梯平台落水 | 至少三个三格宽水平平台及落差，不是单坡 |
| W05 | 开放凹坑积水 | 地下开放坑，无地上容器及出口 |
| W06 | 孤立矮挡板绕流 | 单列矮挡板，可绕过，无围壁 |
| W07 | 狭缝隔挡通水 | 覆盖地图宽度的抬高地形隔挡，唯一可拆窄缝 |

| G01 | 平地自由堆沙 | 无容器、障碍、坡或坑 |

同一类型内按整体几何模板互斥分配。尺寸、投放次数、位置与随机种子只是样本变化，不另起任务ID。不生成组合场景。水任务不放沙，沙任务不放水；静态地形与支撑为DIRT/BRICK等原有材料。

## 形成与操作

新增任务固定32帧：1帧初态、10次搭建/挖坑tick、6次分批投料tick、15次静置tick。搭建逐层从下向上，同层同时放置；挖坑逐层从上向下，避免先挖下层导致上层落下。容器BRICK底面有两侧支撑，宽度6～10在游戏span6范围内。每次tick的真实动作都保存；同一格不能在同帧编码两个动作。未在预算内稳定的样例重试，不压缩物理时间或直接替换成稳定态。

投料按实际成功动作数校验，并与网格内水/沙数量核对。高台两列六轮最多12粒，随机fill为4～12；其他模板为4～18。无法完成声明投料数的样例明确失败重试，不静默截断。

完成状态生成8个操作片段；process使用前4个，shuffle使用相同操作片段。partial从形成第1～27帧选择中间状态、用真实tick稳定后执行操作。

容器与狭缝任务拆指定挡块，其余任务在模板规定的位置放一个水/沙格；所有评测仍是32步后的状态预测，不增加选择/修复等问题类型。两个评测干预可能产生相同结果，保留这种情况，不按影响差值筛选测试。

新任务按模板锚点x保留空间迁移：train4～22，validation25～30，test34～地图允许上界。还检查三划分最终状态哈希隔离。不能将该测试称为训练分布内ID。

## 物理边界

严格沿用 `game_code/core.py`：离散支撑、颗粒下落、水寻找可下降路径；不是现实流体/颗粒模拟。没有水压、摩擦压实、燃烧、电路或植物生长。门不作为水闸。水/沙更新含固定种子随机顺序，生成时记录种子以复现。

## 添加任务

在注册表新增唯一ID、机制类型、模板和边界；实现完整的形成与操作生成器。先加入真实模拟回归，再新建数据版本。不得把已有任务的一个操作或尺寸变体包装成新任务。统一输出shape、四条件定义和metric不能随任务改变。
